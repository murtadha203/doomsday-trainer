# مدرب حساب يوم الأسبوع

موقع تدريب صغير لحساب يوم الأسبوع لأي تاريخ بالعقل: كود القرن وكود السنة يوصلونك
لـ "Doomsday" السنة (يوم أسبوع ثابت)، وبعدها تواريخ شهر ثابتة (4/4، 6/6، 9/5...)
بدل حفظ 12 كود شهر مجرد.

خمس مراحل متدرجة، كل مرحلة تفتح بعد ما تنجح بالي قبلها:

1. كودات القرن
2. كود السنة وإيجاد الـ Doomsday
3. تواريخ الشهر الثابتة
4. العد للتاريخ المطلوب
5. اختبار شامل بتواريخ عشوائية كاملة

**تدريب ذكي:** كل جواب ينسجل مع نوع السؤال (قرن، عقد، شهر، سنة كبيسة، فرق أيام...)
ومدة تفكيرك بيه. الموقع يحيّز الأسئلة الجاية نحو نقاط ضعفك (غلط متكرر أو بطء)
تلقائياً، وفوگ كل مرحلة اكو لوحة "تحليل الأداء" حية تبين وين تحتاج تركيز وآخر
أغلاطك ومتوسط وقتك بكل مرحلة.

التقدم والتحليل ينحفظون بالمتصفح (localStorage)، ما يحتاج سيرفر ولا حساب.

فتح مباشر: انفتح `index.html` بأي متصفح، أو من رابط GitHub Pages مال هذا المستودع.
