# مدرب حساب يوم الأسبوع

موقع تدريب صغير على طريقة الأكواد (Key Value Method) لحساب يوم الأسبوع لأي تاريخ بالعقل.

خمس مراحل متدرجة، كل مرحلة تفتح بعد ما تنجح بالي قبلها:

1. كودات القرن
2. كودات الشهر
3. كود السنة
4. التجميع وقراءة النتيجة
5. اختبار شامل بتواريخ عشوائية كاملة

التقدم ينحفظ بالمتصفح (localStorage)، ما يحتاج سيرفر ولا حساب.
